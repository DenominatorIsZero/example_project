# Web Demo Package

This directory contains the web-deployable version of the AI demo.

## Files

- `index.html` - Minimal HTML wrapper for the demo
- `interactive.js` - JavaScript wrapper generated by wasm-bindgen
- `interactive_bg.wasm` - Optimized WebAssembly binary (20MB)

## Testing with VS Code Live Server

1. Open VS Code in the project root
2. Install the "Live Server" extension if not already installed
3. Right-click on `interactive/web/index.html`
4. Select "Open with Live Server"
5. The demo should load in your browser

## Deploying to Website

This package is designed to work with your existing iframe-based demo template:

1. Copy the entire `web/` directory contents to your website's demo directory
2. Update your demo configuration to point to the `index.html` file
3. The iframe in your template will load and display the demo

## Build Command

To regenerate this package:

```bash
just build-web
```

This will:
1. Build the optimized WASM release binary
2. Generate the JavaScript wrapper with wasm-bindgen
3. Create/update all files in this directory
